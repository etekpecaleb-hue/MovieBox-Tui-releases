# MovieBox-Tui releases

Prebuilt MovieBox-Tui binaries. The app checks this repository's **Releases** to update itself automatically.

| Platform | File |
|---|---|
| Windows x64 | `MovieBox_Windows_x64.zip` |
| Linux x64 | `MovieBox_Linux_x64.tar.gz` |
| Linux arm64 | `MovieBox_Linux_arm64.tar.gz` |
| macOS (Intel + Apple Silicon) | `MovieBox_macOS_Universal.tar.gz` |
| Android / Termux (arm64) | `MovieBox_Android_arm64.tar.gz` |

Every release includes `SHA256SUMS`; the built-in updater verifies downloads against it.
